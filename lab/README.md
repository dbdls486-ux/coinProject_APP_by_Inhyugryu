# 지표 검증 실험실

스윙 매매(며칠~몇 주 보유)에 쓸 매수 신호를 **과거 데이터로 먼저 검증**하는 곳.
여기서 살아남은 규칙만 4시간 스캐너와 AI 검토, 모의 매매 장부에 넘긴다.

## 돌아가는 방식

GitHub Actions(`.github/workflows/lab.yml`)가 실행한다. `lab/` 코드가 바뀔 때와 매주 월요일 아침.

1. `collect.mjs` — 빗썸 원화마켓·바이낸스 USDT마켓 전 종목 일봉을 받을 수 있는 만큼 과거까지 받는다. 원본은 커밋하지 않는다.
2. `run.mjs` — 아래 두 질문을 시장별로 따로 잰다.
3. 결과는 `results/REPORT.md`(사람용)와 `results/latest.json`(앱·AI용)에 커밋된다.

## 판정 방법 (2차 설계, 독립 점검 반영)

**A. 종목 선택력** (`selection.mjs`) — 규칙이 고른 코인이 같은 날, 같은 변동성 5분위의 다른 코인보다 나았나.
- 거래 가능한 모든 (종목, 날짜)에 대해 같은 매도 규칙으로 혼자 거래한 수익을 한 번 계산해 두고, 그날 같은 변동성 구간 전체 평균을 기준으로 뺀다. 무작위 표본이 아니라 전수 평균이라 매수 시점·개수·변동성이 정확히 같다.
- 보유 기간이 겹치므로 Newey-West 로 보정한 t값을 쓴다. 고르는 기간(~2023년)과 확인 기간(2024년~) 모두 t ≥ 2, 로그 수익 기준으로도 플러스여야 통과.
- 무작위로 고르는 위약 규칙 30개를 같이 돌린다. 위약이 통과하면 기준이 느슨하다는 뜻이다.
- 가짜 시세로 확인함: 아무 패턴 없는 시장·변동성 함정 시장에서는 통과 0개, 숨은 모멘텀을 넣은 시장에서는 모멘텀·돌파 규칙이 t 7~9로 통과.

**B. 시기 선택** (`regimes.mjs`, `engine.mjs`) — 같은 규칙을 국면 필터 5가지(항상 / BTC 50일선 위 / 알트 절반 이상 50일선 위 / 알트 지수 50일선 위 / 알트가 BTC보다 강한 흐름)로 실제 계좌처럼 굴린다.
- 비교 기준: BTC 그냥 보유, BTC 50일선 타이밍(`bench.mjs`).
- 후보 = A 통과 + 고르는 기간에 고른 국면 필터로 확인 기간 연수익도 플러스.

**비용**: 빗썸 수수료 한쪽 0.25%·슬리피지 0.15~0.3%, 바이낸스 0.1%·0.05~0.15%, 손절은 슬리피지 2배. 동시 보유 10종목, 유동성 하한(빗썸 20일 평균 거래대금 10억 원, 바이낸스 100만 USDT).

**3차에 추가한 것**: 김치프리미엄 하위·상위 10%, 7일 평균 펀딩비 하위·상위 10%, 자기 50일선 위 추세 규칙. 거래대금 상위 20개만 남긴 메이저 버전. 바이낸스 상장폐지 종목(자료실 월별 파일)과 선물 펀딩비(`archive.mjs`), 두 거래소 마감 시각 차이를 맞춘 김프 계산(`features.mjs`).

**데이터 정리**: 오늘 미완성 봉 제외, 하루 20배 넘게 뛰거나 95% 넘게 빠진 봉 이전 기록은 액면 변경으로 보고 버림, 페이지 연속성·빠진 날 수 기록.

## 사건·국면·메이저 실험 (`run-events.mjs` → `results/EVENTS.md`)

- `events-collect.mjs`: 업비트·바이낸스 상장 첫 거래 시각(공식 캔들 API), 바이낸스 선물 상장(펀딩비 첫 날), 빗썸 상장(일봉 첫 날), 해킹(DefiLlama), 업비트 상장 전후 1시간봉, 메이저 4시간봉.
- 사건이 공개된 뒤 다음 날 시가에 샀을 때를 같은 날·같은 변동성 코인 평균과 비교한다. BTC 50일선 위/아래로도 나눠 본다.
- 급등한 다음 날 매수를 급등의 성격(시장 동반 상승·단독·거래량 쏠림·급등 뒤 눌림)별로 나눠 본다.
- 메이저 코인(BTC·ETH·XRP·SOL·DOGE)에서 추세 타이밍과 "싸면 사고 비싸면 팔기" 규칙을 일봉·4시간봉으로 비교한다.
- 수집 단계에 날짜 쏠림 점검이 있다 (상장 날짜가 매달 1일로 잘못 잡히면 미래 정보가 섞인다 — 실제로 한 번 잡아 고쳤다).

## 급등 예측 지표 검증 (`ml/study.py` → `results/INDICATORS.md`)

파이썬으로 따로 돈다 (`.github/workflows/ml.yml`, `lab/ml/**` 가 바뀔 때와 매주).

- `ml/features.py`: 지표 103개 (이평선·골든크로스·MACD·일목·RSI·스토캐스틱·볼린저·피보나치 되돌림·캔들 모양·거래량·BTC 대비 강도·김치프리미엄·펀딩비 등)와 목표값 (7일 안에 +30% 급등 여부, 비용을 뺀 실수익, 익절·손절 경로).
- `ml/study.py`: 개별 지표 채점 → 신호형 지표와 2개 조합 → 합성 점수와 기계학습 모델 (매년 그 전 자료로만 학습) → 매일 상위 5종목을 7일 들고 가는 계좌.
- `ml/round2.py`: 조건을 바꿔 다시 확인 — 상승장일 때만, 모델이 확신할 때만, 종목 수, 익절·손절·보유 기간 75조합, 4주 보유, 거래대금 상위 종목만, 메이저 코인에 추세·역추세 규칙 적용.
- 무작위 가짜 지표 5개를 같이 채점하고, 신호가 없는 가짜 시세·신호를 심은 가짜 시세로 채점 방식 자체를 확인했다.

## 단계형 시나리오 · 주봉 결합 · 뉴스 결합 (`ml3/study3.py` → `results/SETUPS.md`)

- `ml3/feat3.py`: 주봉 지표(그날로 끝나는 7일을 한 주로 묶음)와 순서형 지표(투매 뒤 버팀, 저점 재확인, 고점·저점 구조 전환, 매집 흔적 등).
- `ml3/study3.py`: 준비 조건 → 방아쇠 → 확인으로 묶은 시나리오, 기준값을 전부 바꿔 보는 가설 묶음, 구조 기반 손절·익절과 계좌 시뮬레이션, 조건 조합 발굴, 모델 재학습, 시장 전체 신호, 뉴스 × 차트.
- `news/collect.py`: 블록미디어 공개 API에서 기사 제목·시각만 받아 작업 캐시에 둔다 (저장소에는 월별 건수만).

## 계단식 하락 뒤 돌파 · 크게 오른 경우의 공통점 (`ml4/study4.py` → `results/WINNERS.md`)

- 계단식 하락 뒤 거래량 동반 상단 돌파를 기준값을 바꿔 가며 검증, 같은 돌파를 직전 상태별로 비교.
- 중앙값 말고 분포(상위 10%, 대박·실패 비율)를 같이 보고, 크게 오른 신호와 나머지를 가르는 진입 직전의 특징을 두 기간에서 확인.
- 28일 안에 2배가 된 경우의 직전 조건과 그 조건으로 샀을 때의 대가.

## 모의매매 (`paper/` → `data/paper/*.json`, `results/PAPER.md`)

검증에서 살아남은 것만 모아 실제처럼 장부를 굴린다. 실제 주문은 내지 않는다. `.github/workflows/paper.yml` 이 4시간마다 돌린다.

- `paper/core.py`: 신호 6종 × 시장 상태 4종 × 과열 여부로 나눈 '기대값 표'와 장부 엔진. 하루를 시가(주문 체결) → 장중(손절·익절) → 종가(만료·평가·새 주문) 세 단계로 처리한다.
- `paper/backtest.py`: 같은 엔진으로 2020년부터 과거를 재현하고, 마지막 날 기준 기대값 표(`playbook.json`)를 만든다. 표는 매주 그 시점까지 끝난 거래만으로 계산한다.
- `paper/live.py`: 바이낸스에서 최신 일봉을 받아 실시간 장부(`state.json`, `equity.json`, `trades.json`)를 갱신한다.
- 엔진 검증: 장부 항등식(평가액 − 시작 자금 = 실현 + 미실현), 엔진이 낸 거래와 따로 계산한 가상 거래의 일치, 여러 번 나눠 돌린 실시간 경로와 한 번에 돌린 결과의 일치를 가짜 시세로 확인했다.

## 후보 규칙과 근거

| 묶음 | 규칙 | 근거 |
|---|---|---|
| 모멘텀 | 7·14·28일 상승률 상위 10%, BTC 대비 강세 | 1~4주 모멘텀이 유의 (Liu·Tsyvinski·Wu, Journal of Finance 2022). 2주가 가장 강하고 4~6주부터 반전 (Dobrynskaya) |
| 추세 | 이평 정배열 전환, 20일 돌파, 돌파 앙상블, 거래량 동반 돌파 | 이평선 타이밍이 낙폭을 줄임 (Detzel 외 2021), 여러 기간 돈치안 돌파 앙상블 (Barbon 2025) |
| 눌림목·역추세 | 상승 추세 속 RSI 조정, RSI(2), 볼린저 하단, 낙폭 과대 | 코인에서는 단기 반전이 약하다는 결과가 많아 대조용 |
| 관심 | 최근 30일 최대 일간 상승률 상위, 거래대금 급증 | 코인에서는 MAX 효과가 양(+)의 방향 (Özdamar 외 2021) |

매도는 매수가 − 2×ATR 손절 + 최대 보유 7·14·28일.

## 한계

- **생존 편향**: 빗썸은 지금 상장된 종목만 받을 수 있어 상장폐지 종목이 빠진다. 바이낸스는 자료실 월별 파일로 상장폐지 종목을 채웠다.
- 빗썸 일봉만 쓴다. 펀딩비·김치프리미엄 같은 수급 지표는 과거 데이터를 모으는 대로 추가한다.
- 조합을 많이 돌릴수록 우연히 좋아 보이는 것이 생긴다. 그래서 확인 기간과 무작위 대조군을 같이 본다.
