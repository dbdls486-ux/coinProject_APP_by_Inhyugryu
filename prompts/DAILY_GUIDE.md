# 데일리 시장 브리프 작성 지침 (매일 09:00 KST)

결과물은 `schema/daily.schema.json`을 만족하는 JSON 한 개를 `data/daily/YYYY-MM-DD.json`에 저장하고
`data/daily/index.json`에 항목을 추가한다.

## 0. 이 문서의 목적 한 줄
**"실제로 왜 가격이 움직였는가"**를 쓴다. "이래서 이러지 않았을까"는 금지. 인과가 명확하지 않아도 **논리적으로 연결된
사슬**이 있어야 하고, 없으면 **"원인 불명"**이라고 쓴다. 원인 불명은 실패가 아니라 정직한 결과다.

## 1. 분석 구간과 데이터
- 기준 시각: 발행일 08:30 KST 전후 조회. `asOf`에 기록.
- 구간: 직전 24시간. 월요일은 금요일 08:30부터 72시간.
- 가격·시총·거래량: CoinGecko. 파생: Coinglass(OI·펀딩비·청산). ETF 흐름: Farside/SoSoValue. 온체인: DefiLlama, 거래소 넷플로우.
- 선정 기준: 시총 상위 300위 이내 **그리고** 24h 거래량 ≥ 시총의 2% **그리고** 주요 거래소 상장. 미달 종목은 `excluded`에 이유와 함께.

## 2. 인과관계 규칙 (가장 중요)
원인으로 적으려면 아래 중 하나를 만족해야 한다.

### 허용 ①: 사건 → 가격 (시간 선후 확인)
- 사건(발표·업그레이드·상장·언락·해킹·규제)의 **시각**과 가격 반응 **시각**을 둘 다 확인한다.
- 사건이 가격 반응 **이후**에 나왔으면 원인이 아니다 → caveat에 "발표 N시간 전 이미 상승 시작"이라고 쓰고 confidence 낮춤.
- **사건과 가격 변동 사이가 5일 이상**이면 직접 원인으로 쓰지 않는다. 단, 아래 ②로 연결되면 허용.

### 허용 ②: 과거 사건 → 측정 가능한 중간 반응 → 가격
- "10월 업데이트 → 11월 8일 상승"처럼 떨어진 사건은, **그 사이에 측정 가능한 반응**이 있을 때만 쓴다.
  예: 업그레이드 후 TVL 2주간 +40% → 거래소 순유출 지속 → 가격 상승. 각 단계에 숫자·날짜를 붙인다.
- 중간 반응이 없으면 그 사건은 **배경**으로만 언급하고 원인 자리에 두지 않는다.

### 허용 ③: 수급 주도
- 선물 OI·펀딩비·청산·현물/선물 거래량비·거래소 넷플로우가 움직임을 설명하면 **그렇게만** 쓴다.
  예: "OI/시총 155%, 선물/현물 6.6배, 숏 청산 $320만 — 레버리지 수급이 주도한 상승. 개별 펀더멘털 촉매는 미확인."
- 수급 주도를 펀더멘털로 포장하지 않는다.

### 금지
- "~일 것으로 보인다", "~때문으로 풀이된다"만 있고 수치·시각이 없는 문장.
- 섹터 전체 내러티브(AI·RWA 등)를 개별 코인 원인으로 쓰는 것 — 그 코인의 거래량·OI가 섹터 평균과 다르게 움직였다는 근거가 있을 때만.
- 시장 전체가 -3% 움직인 날 -4% 움직인 코인에 개별 원인을 붙이는 것 → `nature: ["시장 베타"]`로 처리.

## 3. confidence 등급
- **A**: 사건 확인 + 시각 선후 확인 + 반응 수치(거래량·OI·넷플로우) 확인
- **B**: 사건 확인 + 시간상 합리적이나 반응 수치 미확인, 또는 수급 지표만으로 설명
- **C**: 정황뿐. 이 경우 headline은 "원인 불명 — …"으로 시작

## 4. 구성
1. `regime`: 상승/하락/횡보/혼조 + 2~3문장 (BTC·ETH·전체 시총, 거시 이벤트는 날짜 명시, ETF 흐름)
2. `overview`: BTC / ETH / 전체 시총 / BTC 도미넌스 / BTC·ETH ETF 순유출입 / 전체 청산 규모 / 공포탐욕 (6~10행)
3. `movers`: 상승 3~5 + 하락 2~3. 각각 cause.chain을 **단계 배열**로, flows에 수급 숫자
4. `excluded`: 제외 종목과 이유
5. `highlight`: 오늘 가장 볼 만한 움직임 1개 — 왜 중요한지 3~4문장
6. `sources`: 쓴 자료 전부

## 5. 문체
- 한국어, 짧은 문장, 숫자 우선. 감탄·전망·권유 없음.
- 커밋 메시지: `daily: <date>`
